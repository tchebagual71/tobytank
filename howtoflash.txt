• Best permanent fix: put a small ESP-IDF setup function in your PowerShell profile, then run that function whenever you open a shell.

  Do this once:

  notepad $PROFILE

  If the file does not exist, PowerShell/Notepad will ask to create it. Add this to the end:

  function Use-Idf555 {
      $env:IDF_PATH = 'C:\esp\v5.5.5\esp-idf'
      $env:IDF_TOOLS_PATH = 'C:\Espressif\tools'
      $env:IDF_PYTHON_ENV_PATH = 'C:\Espressif\tools\python_env\idf5.5_py3.11_env'

      $idfToolPaths = @(
          "$env:IDF_PYTHON_ENV_PATH\Scripts"
          "$env:IDF_TOOLS_PATH\cmake\3.30.2\bin"
          "$env:IDF_TOOLS_PATH\ninja\1.12.1"
          "$env:IDF_TOOLS_PATH\xtensa-esp-elf\esp-14.2.0_20260121\xtensa-esp-elf\bin"
          "$env:IDF_TOOLS_PATH\esp-rom-elfs\20241011"
      )

      $existing = $env:PATH -split ';'
      $env:PATH = @($idfToolPaths + $existing | Select-Object -Unique) -join ';'

      Remove-Item 'Env:_IDF.PY_COMPLETE' -ErrorAction SilentlyContinue

      Set-Alias idf.py "$env:IDF_PYTHON_ENV_PATH\Scripts\python.exe"

      Write-Host "ESP-IDF v5.5.5 environment ready"
      cmake --version | Select-Object -First 1
      ninja --version
  }

  Save it, then reload your profile:

  . $PROFILE

  Now each time you open PowerShell, run:

  Use-Idf555
  cd C:\Users\tobyd\Desktop\esp32\tobytank
  & "$env:IDF_PYTHON_ENV_PATH\Scripts\python.exe" "$env:IDF_PATH\tools\idf.py" -p COM3 flash monitor

  Or shorter after Use-Idf555:

  python "$env:IDF_PATH\tools\idf.py" -p COM3 flash monitor

  I would avoid permanently modifying the global Windows PATH with setx for this. ESP-IDF paths are version-specific, and setx PATH can truncate or mangle a long PATH. A profile function is safer and easy to update when ESP-IDF changes.

  If you want it to activate automatically every PowerShell session, add this as the last line of your profile:

  Use-Idf555
